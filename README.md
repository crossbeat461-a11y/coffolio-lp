## Deploy

1. [Vercel](https://vercel.com/new) → Import → `crossbeat461-a11y/coffolio-lp`
2. Framework: **Other** (static)
3. Deploy

If the Vercel project name is not `coffolio-lp`, update `og:url`, `robots.txt`, and `sitemap.xml`.
